# clone-Slither.io

**Цель проекта:** создать многопользовательскую игру (в стиле Slither.io). Игроки подключаются к общему серверу по сети, растят червячков, собирают еду и пытаются обойти друг друга на одной круглой арене. Быстрый рестарт после поражения позволяет сразу вернуться в бой.



**Архитектура и формат**

   •	**Клиент-сервер:** Сервер (Python) хранит авторитетное состояние мира. Клиенты (HTML запускаемые в окне) отправляют ввод и отрисовывают то, что пришло с сервера.

   •	**Управление:** Постоянное движение. Три кнопки: влево, вправо, ускорение.

   •	**Сеть:** Играть можно как по локальной сети, так и через интернет (через публичный IP или туннели типа CloudPub).
